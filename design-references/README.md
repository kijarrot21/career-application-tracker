# Design References (Stitch)

Taruh semua hasil *copy-paste* kode desain dari Stitch (`.html`, `.tsx`, `.jsx`, `.css`, atau screenshot) ke dalam folder ini.

Contoh penamaan file agar mudah dicocokkan:
- `layout-shell.html` (sidebar, topbar, navigasi utama)
- `dashboard.html`
- `applications.html`
- `shortlist.html`
- `jobs.html`
- `interviews.html`
- `documents.html`
- `emails.html`
- `analytics.html`
- `settings.html`
- `auth-sign-in.html` / `auth-sign-up.html`
- `tokens.css` (jika ada konfigurasi warna/font khusus dari Stitch)

> Folder ini sudah di-exclude dari `tsconfig.json` dan `eslint.config.mjs`, jadi aman jika berisi file mentah tanpa mengganggu proses build/lint aplikasi.
